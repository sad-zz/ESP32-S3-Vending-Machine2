# راهنمای GPR برای اکتشاف مواد معدنی / GPR Guide for Mineral Exploration

## فایل‌های موجود / Available Files

### GPR_Mineral_Exploration_Guide_FA.pdf
یک راهنمای جامع به زبان فارسی در مورد فناوری رادار نفوذی زمین (GPR) برای اکتشاف مواد معدنی.

A comprehensive guide in Persian/Farsi about Ground Penetrating Radar (GPR) technology for mineral exploration.

## محتوای راهنما / Guide Contents

این راهنما شامل موارد زیر است:

1. **مقدمه** - Introduction to GPR technology
2. **اصول فنی GPR** - Technical principles and operations
3. **کاربردهای اکتشافی** - Applications in mineral exploration
   - اکتشاف مس (Copper exploration)
   - اکتشاف طلا (Gold exploration)
   - سایر فلزات (Other metals)
4. **نقشه‌برداری و طراحی** - Mapping and survey design
5. **مراحل اجرا** - Implementation stages
   - آماده‌سازی (Preparation)
   - برداشت میدانی (Field work)
   - پردازش داده (Data processing)
   - تفسیر (Interpretation)
6. **تجهیزات و ساخت** - Equipment and construction
7. **مزایا و محدودیت‌ها** - Advantages and limitations
8. **مطالعات موردی** - Case studies
9. **بهترین شیوه‌ها** - Best practices
10. **روندهای آینده** - Future trends

## زبان / Language

This documentation is written in **Persian/Farsi**.

## استفاده / Usage

فایل PDF را باز کرده و مطالعه کنید. این راهنما برای متخصصان ژئوفیزیک، زمین‌شناسان و مهندسان معدن که در زمینه اکتشاف مواد معدنی فعالیت می‌کنند، مفید است.

Open the PDF file to read. This guide is useful for geophysicists, geologists, and mining engineers working in mineral exploration.
